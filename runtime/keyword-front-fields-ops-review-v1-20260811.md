## 2. 双表业务逻辑

```text
每周获取一个一级类目的新快照
  -> 当前批次进入“关键词分析 V1（修正版）”进行字段审核
  -> 同一批数据追加到“关键词历史总表 V1”
  -> 历史总表与最近一次同口径批次比较
  -> 前置字段经运营确认后，再设计重点词、优先级和产品方向
```

两张表的职责必须分开：

- 当前分析表回答“这一批关键词是什么、如何理解、当前搜索和交易热度如何”。
- 历史总表回答“同一关键词跨周是否持续出现，排名、搜索人气和交易转化如何变化”。
- 当前分析表不重复保存趋势字段，避免每周新表自行计算历史后产生不同口径。
- 第一版不做同比，不新增月度、季度或年度汇总表。

## 6. 关键词编号合同

`关键词编号`不能继续使用旧版 `KW-搜索词`公式。

正式规则：

- 唯一匹配键为 `一级类目 + 规范化后的原始关键词`。
- 规范化只允许去首尾空格、统一英文大小写、统一全角半角。
- 同一类目再次出现同一关键词，沿用原编号。
- 不同一级类目绝不共用编号，即使文字相同也分配不同编号。
- 已分配编号永久保留，不删除、不回收。
- 同义词各自有编号，再通过标准归并词聚合。

编号机制已落地：`关键词编号库 V1`以“一级类目 + NFKC 规范化后的原始关键词”为唯一匹配键，通过飞书自动编号生成 `KW` 加 6 位序号；导入脚本查找或追加编号库记录，再把编号作为文本快照回填两张业务表。编号永久保留、不回收，重跑不会重复分配。

## 7. 待运营审核的 AI 提示词

以下提示词只作为运营审核稿，尚未批量运行。

### 标准归并词

```text
你是浴缸关键词归并助手。
输入：原始关键词。
目标：输出一个稳定、简短、可用于跨周统计的标准归并词。

规则：
1. 只合并同义、近义或冗余写法。
2. 材质、安装方式、核心功能、明确尺寸、使用人群和场景不同，不得合并。
3. 不删除会改变产品需求的信息，不推断原词没有表达的属性。
4. 小浴缸、小型浴缸、小户型浴缸、小空间浴缸可候选归并为“小浴缸”。
5. 无法可靠判断时输出空，并把分析状态设为待审核。
6. 只输出标准归并词，不输出解释。
```

### 关键词分类

```text
你是浴缸关键词主分类助手。
只能从以下八类中选择一个：
大词、材质词、场景词、痛点词、款式词、风格词、尺寸词、功能词。

规则：
1. 明确问题或故障表达优先归痛点词。
2. 明确人群或使用场景其次归场景词。
3. 否则选择关键词最主要的产品属性。
4. 纯通用产品词归大词。
5. 品牌、地域和颜色不作为主分类。
6. 无法稳定单选时留空，并把分析状态设为待审核。
7. 只输出一个分类名称。
```

形状词是否统一归入款式词，仍需运营最终确认。

### 细分标签

```text
你是浴缸细分标签提取助手。
只提取原始关键词明确出现的信息，不补充、不推断。

标签顺序：
大词 -> 材质 -> 场景 -> 痛点 -> 款式 -> 风格 -> 尺寸 -> 功能 -> 品牌 -> 地域 -> 颜色。

要求：
1. 同义写法统一，真实产品差异保留。
2. 复合功能拆为独立标签，例如“恒温加热”输出“恒温、加热”。
3. 小户型只标场景，不推导小型；老人不推导安全问题。
4. 单人、双人、多人归尺寸；明确数字尺寸统一单位表达。
5. 没有明确标签时留空，不输出“其他、普通、无标签”。
6. 多个标签使用中文顿号分隔，只输出标签结果。
```

### 用户意图

```text
你是浴缸关键词意图分类助手。
只能从以下五类中选择一个：
了解型、对比型、购买型、灵感型、问题解决型。

规则：
1. 明确故障、清洁、维修或“怎么办”归问题解决型。
2. 明确比较、区别、怎么选、哪个好归对比型。
3. 明确价格、购买、旗舰店、正品、哪里买归购买型。
4. 明确设计、效果图、装修、案例、搭配、图片归灵感型。
5. 小户型、老人、酒店等只有场景但没有上述信号时归了解型。
6. 只输出一个意图名称。
```

## 8. 第一版趋势合同

只有 `一级类目 + 主关键词 + 来源渠道`完全一致的批次才允许比较，并与最近一次同口径批次比较。

### 出现状态

| 状态 | 定义 |
|---|---|
| 首次出现 | 历史从未采集到，本期第一次出现 |
| 连续出现 | 上一个可比批次和本期都出现 |
| 重新出现 | 历史出现过，上期未出现，本期再次出现 |
| 本期未进入采集范围 | 上期出现，本期没有采集到 |

不能把“本期未进入采集范围”直接解释为消失或需求下降。

### 排名环比

- 只对连续出现的关键词计算。
- 计算方式为 `上期排名 - 本期排名`。
- 正数表示上升，负数表示下降，0 表示持平。
- 首次出现、重新出现、本期未进入采集范围均不可比。

### 搜索人气环比与交易环比

- 只比较平台原始区间档位，不计算中值、差值或涨幅。
- 区间上移、未变化、下移分别输出对应文字。
- 任一期为 `-`或新平台区间时不可比或待核验。
- 只对连续出现计算。

### 综合趋势变化

| 输出 | 规则 |
|---|---|
| 强势上升 | 至少两项上升，且没有下降项 |
| 上升 | 至少一项上升，其余未变化或无数据，且没有下降项 |
| 稳定 | 至少一项可比，所有可比项均未变化 |
| 下降 | 至少一项下降，其余未变化或无数据，且没有上升项 |
| 强势下降 | 至少两项下降，且没有上升项 |
| 趋势分化 | 同时出现上升项和下降项 |
| 数据不足 | 三项均不可比 |
| 不可比 | 首次出现、重新出现或本期未进入采集范围 |

当前只有一个可信批次，五个趋势字段保持空值。第二个同口径批次到位后再配置公式和验收。

## 9. 冻结字段

以下字段保留表头，但当前不运行公式或 AI：

- 内容热度（后续）：缺少真实内容平台数据，取消旧 AI 预测。
- 是否重点词：长期稳定性口径待前置字段运营确认后再启用。
- 优先级：代表短期风口和时间紧迫性，暂不提前设计。
- 对应产品方向：需要联动前置分类、标签、热度和趋势，暂不提前设计。

重点词的暂定业务方向为“长期稳定出现的关键词”；优先级的业务方向为“短时间需要抓住的风口词”。二者不能使用同一个公式替代。
