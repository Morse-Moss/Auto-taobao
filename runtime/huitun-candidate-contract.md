# 灰豚候选与优先级状态合同 V3

更新时间：2026-08-16

这份合同只定义“内容热度/灰豚/优先级”三者的边界。`对应产品方向`由历史同步后的三个近两周达标次数计算，不参与灰豚队列，也不由灰豚浏览量直接推断。

## 字段责任

| 字段 | 责任方 | 灰豚阶段是否可写 |
| --- | --- | --- |
| `内容热度` | 上游内容平台数据或飞书 AI 分析 | 否，只读 |
| `灰豚话题浏览量` | 灰豚红薯版“话题搜索”精确同名查询 | 是，唯一允许写入字段 |
| `优先级` | 飞书公式 | 否，只等待公式收敛 |
| `对应产品方向` | 飞书公式（近两周三类达标次数） | 否，只读 |

## 进入灰豚的条件

- 只有飞书公式产生的 `优先级=A候选` 才进入默认灰豚队列。
- `A候选` 的前置条件是：非品牌词，`搜索热度`为`中/高`，`交易热度=高`，`内容热度`为`中/高`，且 `灰豚话题浏览量`尚未回填。
- 在选择队列前，真实关键词的 `优先级` 不能为空或仍为 `待数据`；否则返回 `AI_REQUIRED`，不打开灰豚页面。
- `搜索热度`由搜索人气分档得到，灰豚不直接解析搜索人气区间文本。
- 当前 7 天搜索人气映射：`1200 ~ 2500`及以上为`高`，`600 ~ 1200`为`中`，`300 ~ 600`及以下的已知平台区间为`低`；未知区间输出`待核验`。只按平台显示区间映射，不计算区间中值。

## 灰豚采集与写入

- 只接受去除首尾 `#` 后与搜索词完全一致的话题；相近话题不合并、不累加。
- 保留灰豚页面显示的原始值（例如 `109.4w`、`1,314`、`-`），另存可校验的数字值用于飞书数值字段。
- 查无完全同名话题时，写入 `灰豚话题浏览量=0`，并保留“无同名话题”的证据文本。
- `--apply` 的写入白名单只有 `灰豚话题浏览量`。不写、不推导、不覆盖 `内容热度`，也不写公式、`是否重点词` 或 `对应产品方向`。
- 已有非空浏览量与本次结果不一致时拒绝覆盖；已有内容热度无论为空还是有值，均由上游流程负责。

## 采集后的优先级

- `灰豚话题浏览量 >= 10,000,000` 只是 A 条件的浏览量门槛，不是内容热度的替代值。
- 只有当上游 `内容热度=中/高`、`搜索热度=中/高`、`交易热度=高` 且浏览量达到门槛时，飞书公式才应收敛为 `A-立即跟进`。
- 浏览量已回填但未满足完整 A 条件时，按现有公式收敛为 `B-持续观察` 或 `C-常规跟踪`。
- 灰豚结果不会把内容热度强行改成“高/低”；运营尚未确认的内容热度分档继续由上游规则维护。

## 安全与验收

- 默认 dry-run；只有显式 `--apply` 且 `--confirm-table` 与当前表 ID 完全一致时才允许写入。
- 写入前保存表结构和记录快照，写入后验证字段定义、记录数、所有非灰豚字段（特别是内容热度和是否重点词）以及优先级公式收敛。
- 登录、验证码、风控、安全、权限提示进入 `HUMAN_REQUIRED`；查询停滞进入 `STALLED`；不重试绕过平台控制。
- `对应产品方向` 只按近两周达标次数公式计算，不因为单次灰豚浏览量直接生成。
- 灰豚是**独立段**，没有编排器串它（2026-09-20 核对）。`run-weekly-post-ai.mjs` 只做编号库 creates、当前表 updates、历史表 updates 三件事，不调用灰豚、也不在灰豚返回后继续历史同步 —— 顺序（先灰豚、后 `sync-decision-history.mjs`）由人工排，不由代码保证。`DONE_NO_CANDIDATES` 只表示灰豚段没候选，不触发任何下游阶段。

## 业务默认值

- 保修不参与当前关键词、重点词、优先级或灰豚采集判断。
- 后续业务输出需要保修年限且没有其他明确约定时，默认 3 年。
