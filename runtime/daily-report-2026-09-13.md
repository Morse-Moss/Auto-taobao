## 二、问题清单（现象 / 原因 / 方案 / 状态）

### #1 小旺神 XLSX 导出菜单点击失败
- 现象：40 页采集完成后 CSV 正常落盘，XLSX 点击报"菜单 missing or ambiguous"
- 原因：CSV 下载后留下的下拉菜单中间态，把菜单状态机的"新出现"标记搞乱
- 方案：exportXlsx 菜单匹配加两阶段兜底（前 2 秒仅接受新出现项，之后放宽为可见+文本精确匹配）
- 状态：已解决（重跑单次完成采集+CSV+XLSX）

### #2 误重跑导致重复采集
- 现象：XLSX 失败后重跑同命令，从第 1 页重新采集而非续接
- 原因：裸跑 export-market-analysis.mjs 不写 PG、无断点；"恢复"只结算导出意图
- 方案：切换正确入口 run-adaptive-export.mjs（PG 断点 + stall 自动续段 + 合并），杀掉误跑任务
- 状态：已解决（当日完成 6 段自适应采集 1462 行）

### #3 SKU 采集被淘宝拦截
- 现象：商品详情页打开即跳"访问被拒绝"风控页
- 原因：调试 Edge 登录的是商家账号（千牛调试时顶替了买家登录），淘宝新规禁止商家账号看别家店铺详情页
- 方案：人工切换买家账号登录（登录属人工边界不自动化）
- 状态：已解决（切换后详情页可正常打开）

### #4 本周唯一 A 类竞品已下架
- 现象：详情页跳"宝贝不存在，可能已下架或被转移"
- 原因：SSWW 浪鲸深泡浴缸（678598686014，月收 82 人/21.3 万）在数据周期后下架；交叉验证搜索结果确认
- 方案：经用户拍板按"无可采 A/B"跳过 SKU/尺寸富化；FAQ 按下架商品 0 行证据口径走完空周期
- 状态：已解决（流程闭环）

### #5 API 烧钱第一轮（全天 $20.4）
- 现象：用户发现余额被大量消耗，截图怀疑 Edge SharedWorker 循环调用
- 原因：查网关用量日志，真凶是 Codex Desktop（alpha 版）反复调用（UA 铁证），SharedWorker 源码只是自增 id 发号器与烧钱无关；余额耗尽后请求被拒才停
- 方案：完整归因报告给用户，提供关进程/禁 key/设限额三个止血选项
- 状态：已解决（归因明确），限额方案待用户决定

### #6 API 烧钱第二轮（12:30-14:00 $15.89）
- 现象：用户质疑该时段 Codex 调用非本人操作，怀疑助手分析模块调用
- 原因：查 usage_logs 该时段 726 请求全部 UA=Codex Desktop、走 CODEX key、本机 IP，无其他客户端；助手分析模块走 GLM 不经此 key，机制上排除。部分请求（13:00 后约 350 发）无会话记录、固定缓存+27 输出 token，属 Codex Desktop IDE 插件后台重试形态
- 方案：逐段还原调用来源；确认用户本人 12:38 曾在 Codex 调试外部浏览器能力
- 状态：已解决（归因明确），限额建议待用户决定

### #7 Codex 桌面端"没有文件写入/终端工具"复发
- 现象：Codex 会话自述无本地文件写入与终端能力，无法修改项目文件
- 原因：config.toml 的 model_provider 被 CC-Switch 切中转时写回 ccswitch（走 sub2api 桥），大上下文下桥转发丢 spawn_agent 参数（rollout 铁证：108 次调用 js 参数完整、spawn_agent 全空 {}）；threads 表 3340 个历史会话钉死 ccswitch
- 方案：备份后 config 改回 apizh 直连 + threads 表批量纠正 + headless 验证通过；复发开关与两分钟修复套路写入 codex-workspace-restricted skill
- 状态：已解决（待用户完全退出并重启 Codex 生效）

### #8 仪表盘"竞品周期过去 7 天"无数据
- 现象：竞品周仪表盘四个占比/排名图表显示"当前暂无数据"，但数据昨天已导入
