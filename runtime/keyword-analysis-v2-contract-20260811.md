# 关键词分析 V2 测试合同

## 范围

- 仅适用于 `关键词分析 V1（修正版）`（`tblN1uT1LpzyqqWx`）。
- 本轮更新现有四个 AI 字段的 Prompt 与承载结构，不新增字段、不写记录、不触发 AI 生成。
- 历史表、关键词编号库和已停用的空测试表不在本轮修改范围。

## 已冻结口径

- 关键词分类为九类单选：大词、材质词、场景词、痛点词、款式词、风格词、尺寸词、功能词、品牌词。
- 不新增关键词副分类；复合属性进入受控的细分标签多选。
- 品牌不独立成列；品牌加通用品类时由主分类 `品牌词` 承接。
- 标准归并只处理不改变需求的同义或冗余写法，禁止向上归类；无法确认时回退原始关键词。
- `小浴缸`与`小户型浴缸`不得自动归并；`步入式浴缸`不得推断为靠墙式。
- 用户意图由同一 AI Prompt 内的信号规则判断；多类同时命中时按问题解决、对比、购买、灵感、了解取最高优先级。
- 内容热度、是否重点词、优先级和对应产品方向继续冻结。

## 字段边界

- 保留现有22列和300行，不增加 `品牌`、`意图判定依据`、`批次编号`。
- `标准归并词`由单选改为文本，支持无法确认时原样回退任意原始关键词。
- `关键词分类`保留旧选项 ID 并新增`品牌词`。
- `细分标签`保留旧选项以保护历史单元格，并追加完整的`维度/标签`受控字典；AI 全量覆盖后再单独评估清理旧选项。
- `用户意图`保留五类有效选项及其 ID，只移除未被记录使用的异常长文本选项。
- 其他字段类型、公式、选项与全部现有单元格内容不变；原表继续使用既有的 `来源渠道` 字段名。
- 内容热度、是否重点词、优先级和对应产品方向继续冻结。

## AI Prompt

本地四个 Prompt 以 `{{原始关键词}}` 标记输入位置。飞书富文本编辑器的现有芯片不能稳定
重新插入，因此实际保存策略为保留旧芯片并在末尾追加“新版规则覆盖段”：

1. 关键词分类
2. 细分标签
3. 标准归并词
4. 用户意图

`标准归并词`与`用户意图`已保存为完整新版文本并保留真实字段引用；`关键词分类`、`细分标签`
保留原 Prompt 和原有芯片，再追加新版覆盖段。细分标签原有芯片为 `搜索词`，当前与
`原始关键词`逐行一致，追加段已明确这一输入口径。

Prompt 的唯一代码来源为 `keyword-analysis-v2-core.mjs`。测试要求每段 Prompt 都含输入锚点，
并覆盖九类分类、受控标签、保守归并和规则未命中兜底边界。
