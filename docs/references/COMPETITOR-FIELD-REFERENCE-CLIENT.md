# 浴缸竞品分析表：字段、公式与 AI 提示词

目标 base：**浴缸竞品分析**（飞书多维表格）

目标表：

- **竞品主表** — 36 个字段，全量历史，是所有字段定义的基准；
- **竞品周表** — 每周新建一张，35 个字段，承载当周的采集数据与统计。

本文逐字段说明处理方式、需要在飞书侧配置的公式，以及 AI 字段提示词全文。
文中字段类型、字段个数、公式结构均为针对线上表逐项核对的结果，不是设计稿。

> **怎么用这份文档**：第一节是字段处理矩阵，用来核对手上这张表每个字段归谁负责；第二节是可直接配置的飞书公式；第三节是可直接粘贴到飞书 AI 字段的提示词；第四节是受控词表与归一化对照；第五节是必须知道的边界与待确认事项。

---

## 一、字段处理矩阵

处理方式只有五类：**小旺神原值**（采集导出，原样保留）、**导入时写入**（导入程序固定写入）、**飞书公式**（表格自动重算，无需人工填）、**飞书 AI**（由提示词识别填充）、**汇总/关联**（由关联表自动带出）。

### 1.1 竞品主表（36 个字段）

| # | 字段 | 处理方式 | 当前动作 |
|---:|---|---|---|
| 1 | 序号 | 小旺神原值 | 保留，不修改（每份导出都从 1 重排，不是全局唯一） |
| 2 | 商品图片 | 小旺神原值（图片） | 保留，以附件形式上传 |
| 3 | 商品标题 | 小旺神原值 | 保留。**所有公式判断与 AI 识别的唯一文字依据** |
| 4 | 商品链接 | 小旺神原值 | 保留，同时作为合并去重键 |
| 5 | 价格 | 小旺神原值（数字） | 保留，不换算单位、不补缺失值 |
| 6 | 月收货人数 | 小旺神原值 | 保留原样，包括 `100+` 这类区间下限写法；不改写成数字 |
| 7 | 类目 | 小旺神原值 | 保留，但**不参与**「是否有效竞品」判断（来源数据里配件也会被归到浴缸类目） |
| 8 | 同款数 | 小旺神原值 | 保留，不修改 |
| 9 | 平台 | 小旺神原值 | 保留（淘宝 / 天猫） |
| 10 | 占位类型 | 小旺神原值 | 保留，不修改 |
| 11 | 店铺名 | 小旺神原值 | 保留，不修改 |
| 12 | 店铺旺旺 | 小旺神原值 | 保留，不修改 |
| 13 | 店铺类型 | 小旺神原值 | 保留，不修改 |
| 14 | 地址 | 小旺神原值 | 保留，不修改 |
| 15 | 收藏人数 | 小旺神原值 | 保留，不修改 |
| 16 | 卖点 | 小旺神原值 | 保留；`功能` 的 AI 识别允许读它 |
| 17 | 搜索关键词 | 导入时写入 | 固定为当次采集关键词（如「浴缸」） |
| 18 | 是否有效竞品 | 飞书公式 | 自动重算：是 / 否 / 待确认 |
| 19 | 排除原因 | 飞书公式 | 自动重算：非浴缸主体 / 服务类 / 浴缸配件；有效或待确认留空 |
| 20 | 月收货人数计算值 | 飞书公式 | 自动重算：`100+` 取下限 100，纯数字取原值，不可计算留空 |
| 21 | 计算口径 | 飞书公式 | 自动重算：精确值 / 下限值 / 不可计算 |
| 22 | 月收货金额 | 飞书公式 | 自动重算：价格 × 月收货人数计算值；缺任一项留空 |
| 23 | 客单价带分类 | 飞书公式 | 自动重算：1000以下 / 1000-3000 / 3000-6000 / 6000-8000 / 8000以上 |
| 24 | 竞品分类 | 飞书公式 | 自动重算：A-爆款 / B-高价值 / C-差异化 / D-价格流量 / 无分类 / 不适用 |
| 25 | 待补数据项 | 飞书公式 | 自动重算：列出该条还缺哪些分析信息 |
| 26 | 数据状态 | 飞书公式 | 自动重算：无缺项=可用；有缺项=部分待补 |
| 27 | 材质分类 | 飞书 AI | 使用提示词 A，受控词表；另有确定性识别规则（见 §4） |
| 28 | 外形 | 飞书 AI | 使用提示词 B，受控词表 |
| 29 | 安装方式 | 飞书 AI | 使用提示词 C，受控词表（含「台上/搁置」，业务已确认保留） |
| 30 | 功能 | 飞书 AI | 使用提示词 D，受控词表；可读商品标题与卖点 |
| 31 | 风格 | 飞书 AI | 使用提示词 E，受控词表 |
| 32 | 尺寸 | 汇总（Lookup） | 从 SKU 明细汇总而来，不在本表手填 |
| 33 | 适用空间 | 汇总（Lookup） | 同上 |
| 34 | SKU采集明细 | 双向关联 | 由 SKU 明细侧建立关系时，表格自动生成的反查字段 |
| 35 | 商品ID | 导入时写入 | 淘宝商品 id，也是 SKU 采集的入口参数。**只有本周出现的记录才有值** |
| 36 | 当前周状态 | 主表侧维护 | 两个取值：本周出现 / 本周未出现。主表用它区分周期；周表里每一条都是本周的，这一列在周表上是恒定的 |

### 1.2 周表专有字段（5 个，主表没有）

| 字段 | 处理方式 | 当前动作 |
|---|---|---|
| 商品周期唯一键 | 导入时写入 | 幂等键，防止同一周期重复导入 |
| 数据开始日期 / 数据结束日期 | 导入时写入 | 业务周期（如 2026-09-13 ~ 2026-09-19） |
| 采集时间 | 导入时写入 | 实际采集当天。**它不等于周期结束日**，周表命名用的是采集日 |
| 主表记录ID | 导入时写入 | 回指竞品主表记录 |

### 1.3 周表与主表的字段差异（重要）

新建周表时**只复制结构，不复制数据**，并补上 5 个周表专有字段。主表 36 个字段里，只有 1 个不出现在周表上：

**周表 40 = 主表 36 − 1 + 5**

| 差异项 | 原因 |
|---|---|
| SKU采集明细（主表有，周表没有） | 双向关联字段。每条 SKU 记录归属于**竞品主表**的一条商品，不归属于某一周；而且在周表上再建一次同样的关联，会给「SKU明细」多生成一个反向字段，与主表那个冲突。 |

其中 4 个字段——`尺寸`、`适用空间`、`数据状态`、`待补数据项`——**在周表上同样存在**：前两个是从 SKU 明细汇总来的引用字段，后两个是公式字段。它们的表达式里写死了「当前这张表」的表 ID 和字段 ID，所以**由建表流程在建表当天按新周表重新生成**，不能照抄主表（照抄会指向主表）。

由此带来一个必须知道的实际影响：**周表上的「数据状态」「待补数据项」是按周表自己的数据算的**。这一周还没做 SKU 汇总时，`尺寸` / `适用空间` 是空的，所以「待补数据项」会稳定地把这两项报出来——这是**正常且正确**的提示，不是字段出错。属性列（材质分类 / 外形 / 安装方式 / 功能 / 风格）是否填齐，同样可以直接看这两个字段。

## 二、飞书公式

以下为便于人工检查的**字段名版本**。表格实际保存时会把每个字段引用写成内部字段 ID 引用，逐字段展开后单条公式约 2500 ~ 8200 字符。

配置到自己的表时，把 `[字段名]` 替换成实际的字段引用即可；**不要手抄线上公式**，因为它写死了字段 ID，换一张表就会失效。

### 2.1 前置闸门（下面每个公式的第一步都是它）

```text
有效闸 = AND(
  命中浴缸类词,
  NOT(命中非浴缸词),
  OR(命中主体词, AND(NOT(命中主体词), NOT(命中服务词), NOT(命中配件词), NOT(命中儿童便携)))
)
```

其中「命中 X 词」在表格里的写法就是 `FIND("X", [商品标题])` 逐词展开。各词表：

| 词表 | 词 |
|---|---|
| 浴缸类词 | 浴缸、浴桶、浴盆、洗澡盆 |
| 主体词 | 成人、大人、老人、独立式、嵌入式、靠墙式、深泡、可移动 |
| 非浴缸词 | 洗脚池、洗脚盆、泡脚盆、足浴、宠物、狗洗澡、猫洗澡、婴儿、新生儿 |
| 服务词 | 上门安装、维修服务 |
| 配件词 | 龙头、花洒套装、角阀、下水器、排水器、盖板、扶手、靠枕 |
| 儿童便携 | 同时命中「儿童」与（浴盆、澡盆、折叠、充气、便携）中任意一个 |

> 说明：单独出现「浴盆 / 澡盆 / 洗澡盆」本身**不作为排除依据**，只有在同时命中「儿童」时才排除。

### 2.2 是否有效竞品

```text
IF(
  OR(命中非浴缸词), "否",
  IF(
    OR(命中主体词), IF(OR(命中浴缸类词), "是", "待确认"),
    IF(
      OR(命中服务词), "否",
      IF(
        OR(命中配件词), "否",
        IF(
          AND(FIND("儿童",[商品标题]), OR(FIND("浴盆",[商品标题]),FIND("澡盆",[商品标题]),FIND("折叠",[商品标题]),FIND("充气",[商品标题]),FIND("便携",[商品标题]))), "否",
          IF(OR(命中浴缸类词), "是", "待确认")
        )
      )
    )
  )
)
```

### 2.3 排除原因

```text
IF(
  OR(命中非浴缸词), "非浴缸主体",
  IF(
    OR(命中主体词), "",
    IF(
      OR(命中服务词), "服务类",
      IF(
        OR(命中配件词), "浴缸配件",
        IF(AND(FIND("儿童",[商品标题]), OR(FIND("浴盆",[商品标题]),FIND("澡盆",[商品标题]),FIND("折叠",[商品标题]),FIND("充气",[商品标题]),FIND("便携",[商品标题]))), "非浴缸主体", "")
      )
    )
  )
)
```

### 2.4 月收货人数计算值

```text
IF(NOT(有效闸), "", IFERROR(VALUE(SUBSTITUTE([月收货人数], "+", "")), ""))
```

### 2.5 计算口径

```text
IF(
  NOT(有效闸), "",
  IF(
    RIGHT([月收货人数], 1) = "+", "下限值",
    IFERROR(IF(VALUE([月收货人数]) >= 0, "精确值", "不可计算"), "不可计算")
  )
)
```

### 2.6 月收货金额

```text
IF(
  OR(NOT(有效闸), ISBLANK([价格]), [月收货人数计算值] = ""),
  "",
  [价格] * [月收货人数计算值]
)
```

### 2.7 客单价带分类

```text
IF(
  OR(NOT(有效闸), ISBLANK([价格])), "",
  IF([价格] < 1000, "1000以下",
    IF([价格] < 3000, "1000-3000",
      IF([价格] < 6000, "3000-6000",
        IF([价格] < 8000, "6000-8000", "8000以上"))))
)
```

### 2.8 竞品分类（A / B / C / D 的核心）

```text
IF(
  OR(NOT(有效闸), ISBLANK([价格])), "不适用",
  IF(
    AND([月收货人数计算值] >= 80, [月收货金额] >= 200000), "A-爆款竞品",
    IF(
      AND(FIND("人造石", [材质分类]) > 0, [月收货人数计算值] >= 10), "B-高价值竞品",
      IF([价格] >= 8000, "C-差异化竞品",
        IF([价格] < 1000, "D-价格/流量型竞品", "无分类"))
    )
  )
)
```

判定顺序与含义：

| 分类 | 条件 | 业务含义 |
|---|---|---|
| 不适用 | 前置闸门不通过，或价格为空 | 不是成人浴缸主体，或数据不足，不参与评级 |
| A-爆款竞品 | 月收货人数计算值 ≥ 80 且 月收货金额 ≥ 200000 | 销量与成交额双高 |
| B-高价值竞品 | 材质分类含「人造石」且 月收货人数计算值 ≥ 10 | 高客单价材质，有最低销量 |
| C-差异化竞品 | 价格 ≥ 8000 | 高价格带，走差异化 |
| D-价格/流量型竞品 | 价格 < 1000 | 低价格带，走流量 |
| 无分类 | 以上都不满足 | 中间价格带且销量不足 |

> **配置注意**：B 类判断里的 `FIND("人造石", [材质分类])` 在线上是**直接写的，没有包容错函数**。如果 `[材质分类]` 为空或是「无注明」，`FIND` 会返回错误值，从而影响该条的分类结果。
> 建议在配置到自己的表时改写成 `IFERROR(FIND("人造石",[材质分类]), 0) > 0`，这样材质未填的记录会安稳落到 C/D/无分类，而不是变成一个错误值。
> 另：B 类依赖 `[材质分类]` 有值——**属性列（AI 识别列）没填，B 类就识别不出来**。

### 2.9 待补数据项

```text
IF(NOT(有效闸), "", IF(缺项文本 = "", "", LEFT(缺项文本, LEN(缺项文本) - 1)))
```

其中「缺项文本」是对以下 8 个字段逐个判断后拼接出来的：`月收货人数精确值、材质分类、外形、安装方式、功能、风格、尺寸、适用空间`。
逐个的写法是 `IF(该字段为空 或 = "无注明" 或 = "不适用", "字段名、", "")`，再用 `CONCATENATE` 串起来。最后用 `LEFT(..., LEN(...)-1)` 去掉结尾多余的那个顿号。

### 2.10 数据状态

```text
IF(NOT(有效闸), "", IF([待补数据项] = "", "可用", "部分待补"))
```

### 2.11 一条设计约束（配置时容易踩的坑）

下游公式**不要引用「是否有效竞品」这个公式字段本身**，而是把「有效闸」那段布尔表达式重新展开一遍。

原因：如果让公式字段互相引用，表格的依赖链会不收敛，重算可能一直排不上或报循环依赖。所以线上把「有效闸」这段拿来做公共子表达式，这也正是单条公式长到几千字符的原因。

## 三、AI 提示词

5 个属性字段各用一条提示词。**逐字段粘贴，不要把多段合并到一条里**。
使用时把 `{{字段}}` 占位替换为飞书 AI 字段面板里插入的真实字段引用。

### A. 材质分类

```text
只有当是否有效竞品={{是否有效竞品}}为"是"时才分析；否则输出"不适用"。
从商品标题中提取明确材质，只能输出：亚克力、人造石、塑料、陶瓷、钢瓷、铸铁、透明、木、搪瓷。多个材质用中文顿号分隔，没有明确证据时输出"无注明"。
商品标题={{商品标题}}。
运营归类优先级：PMMA、高分子、绮美石、可丽耐、杜邦石、亚克力人造石全部归为"人造石"；单独出现"亚克力"才归为"亚克力"；命中上述人造石别名时不要重复输出"亚克力"。不得推断标题未提供的材质。
```

### B. 外形

```text
只有当是否有效竞品={{是否有效竞品}}为"是"时才分析；否则输出"不适用"。
从商品标题={{商品标题}}中提取明确外形，只能输出：椭圆、方形、蛋形、异形、正圆。长方形统一归入方形。多个值用中文顿号分隔；没有明确证据时输出"无注明"。只提取标题文字，不得推断。
```

### C. 安装方式

```text
只有当是否有效竞品={{是否有效竞品}}为"是"时才分析；否则输出"不适用"。
从商品标题={{商品标题}}中提取明确安装方式，只能输出：独立、嵌入、靠墙、台上/搁置。独立式归独立，嵌入式、内嵌式归嵌入，靠墙式归靠墙，台上式、搁置式归台上/搁置。多个值用中文顿号分隔；没有明确证据时输出"无注明"。不得根据常识推断。
```

### D. 功能

```text
只有当是否有效竞品={{是否有效竞品}}为"是"时才分析；否则输出"不适用"。
从商品标题={{商品标题}}和卖点={{卖点}}中提取明确功能，只能输出：普通、按摩、智能、恒温。冲浪、水疗、气泡按摩、空气按摩统一归入按摩；加热、保温不自动归入恒温。多个值用中文顿号分隔；没有明确证据时输出"无注明"。"普通"仅在标题明确写出普通浴缸时输出，不得用缺少其他功能反推普通。
```

### E. 风格

```text
只有当是否有效竞品={{是否有效竞品}}为"是"时才分析；否则输出"不适用"。
从商品标题={{商品标题}}中提取明确风格，只能输出：极简、奶油、日式、轻奢。极简风、简约、简约风、现代简约、现代简约风归极简；奶油风、奶油系归奶油；日系、和风归日式；轻奢风归轻奢。侘寂、原木、北欧不归日式；高端、豪华、奢华不归轻奢；"现代"单独出现不归极简。多个值用中文顿号分隔；没有明确证据时输出"无注明"。不得推断。
```

### 三条提示词共用的骨架（改写时别拆掉）

1. **有效性门控**：先看 `是否有效竞品`，不是「是」就输出「不适用」，不分析。
2. **只取明确文字**：只从 `商品标题` 里明确写出的文字取标签（`功能` 额外允许看 `卖点`）。不凭图片猜、不凭常识补、不推断。
3. **归一到受控词表 + 无证据兜底**：命中后归一化到词表内的值；标题里没有明确证据就输出「无注明」；多个值用中文顿号分隔。

### 关于「尺寸」「适用空间」两个字段

早期为这两个字段写过 AI 提示词，但**当前线上这两个字段是汇总（Lookup）字段，不是文本 AI 字段**，所以那两条提示词当前不生效。提示词内容保留如下，仅作为将来若改回 AI 提取形态时的成文口径：

```text
尺寸：从商品标题={{商品标题}}中原样提取明确出现的浴缸尺寸或长宽高，保留数字和单位；多个尺寸用中文顿号分隔。没有明确尺寸时输出"无注明"，不得根据单人、双人、小户型等描述推算尺寸。
```

## 四、受控词表与归一化对照

AI 提示词一律要求「归一到受控词表」，下表是把标题里的常见写法换成受控值的对照。这张表是提示词规则的可读版本，改提示词时必须同步改它。

| 字段 | 受控词表 |
|---|---|
| 材质分类 | 亚克力、人造石、塑料、陶瓷、钢瓷、铸铁、透明、木、搪瓷 |
| 外形 | 椭圆、方形、蛋形、异形、正圆 |
| 安装方式 | 独立、嵌入、靠墙、台上/搁置 |
| 功能 | 普通、按摩、智能、恒温 |
| 风格 | 极简、奶油、日式、轻奢 |

（以上各字段还可输出两个非词表值：**无注明** = 标题里没有明确证据；**不适用** = 该条不是有效竞品。）

|---|---|
| 长方形 | 方形 |

**明确不归类的写法**（防止 AI 过度联想）：

- 加热、保温 ≠ 恒温；
- 侘寂、原木、北欧 ≠ 日式；
- 高端、豪华、奢华 ≠ 轻奢；
- 单独的「现代」≠ 极简；
- 「普通」只在标题明确写「普通浴缸」时输出，不用「缺少其他功能」反推；
- 单独出现「浴盆 / 澡盆 / 洗澡盆」不作为排除依据。

### 材质分类的确定性识别规则

五个属性里，只有 `材质分类` 有一条不依赖 AI 的确定性规则：在标题中找**最早命中**的材质词，同一位置取更长的那个；`PMMA / 高分子 / 绮美石 / 可丽耐 / 杜邦石 / 亚克力人造石` 全部归一为「人造石」（所以「亚克力人造石」判为人造石，不是亚克力）；没有任何命中则输出「无注明」。

抽样校验：用该规则重新推导历史周表已有人工/AI 标注的字段，**一致率约 94%**。需要说明口径——已标注的结果多为**多值**（如「人造石、透明」），而确定性规则只输出**最早命中的单一材质**，剩下不一致的部分主要就是「多值 vs 单值」以及「不适用 → 无注明」这类占位差异。所以准确的说法是：**在「首个材质」这个粒度上一致率约 94%**。

**外形、安装方式、功能、风格这四个没有确定性规则**，它们的值只能来自 AI 或人工，必须把提示词配上才会自动生成。

## 五、使用边界与待确认事项

1. **属性列需要真正跑起来才有值。** 材质分类 / 外形 / 安装方式 / 功能 / 风格五列是 AI 识别列，新建周表时是空列。只有把提示词配置上去（或人工填）才会有值。其中**材质分类为空会直接导致 B-高价值竞品识别不出来**（B 类条件依赖材质分类含「人造石」）。材质分类另有确定性规则可批量填补，其余四列目前只能靠 AI 或人工。
2. **周表同样能看到「还缺什么」。** 周表上也有「待补数据项」「数据状态」两个提示字段，按周表自己的数据重算。其中 `尺寸` / `适用空间` 是从 SKU 明细汇总来的，这一周还没做 SKU 汇总时它们是空的，所以「待补数据项」会稳定地报出这两项——这是正常提示，不是字段出错。
3. **AI 字段保存会立即批量运行，注意额度。** 飞书在保存 AI 字段配置时若对整表立即执行，会一次性消耗大量额度。建议先在少量记录上验证提示词效果，再对全表放开。
4. **`安装方式` 的「台上/搁置」已确认保留。** 早期需求里 `安装方式` 只列了「独立、嵌入、靠墙」三项，当前实现多了「台上/搁置」一档（提示词里也额外写了「台上式、搁置式」的归一）。业务已确认保留：采集到的标题里确实有台上式、搁置式浴缸，去掉会把这类商品判成「无注明」。其余三项（外形 / 功能 / 风格）的词表与需求完全一致。
5. **`尺寸` / `适用空间` 当前是汇总字段。** 它们从 SKU 明细汇总，不在竞品表手填，前面那两条 AI 提示词也不生效。
6. **公式里的字段引用是写死的。** 单条公式逐字段展开后 2500 ~ 8200 字符，全部写死当前表的字段 ID。**复制公式到另一张表会失效**，必须用本文第二节的可读版本重新生成，或按字段引用逐项替换。
7. **`竞品分类` 的 B 段建议加容错。** 见 §2.8 的配置注意：`FIND("人造石", [材质分类])` 在材质为空或为「无注明」时会返回错误值，建议改成 `IFERROR(FIND("人造石",[材质分类]), 0) > 0`。
8. **评级完全由公式算，不接受手工改值。** A/B/C/D 全部由 `竞品分类` 公式自动重算；手工覆盖会在下次重算时被冲掉。要调整评级口径，改公式，不改单元格。
