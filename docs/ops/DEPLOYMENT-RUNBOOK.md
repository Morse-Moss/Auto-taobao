**口径必须一起读，否则这三个数会被误用：**

- B-4 的 **51 ≠ 53**：`discoverSkillTests()` 发现 **53** 个，其中 **2 个**被 `run-test-suite.mjs` 的 `EXCLUSIONS` 划给 `integration` 套件（`skills/sycm-to-feishu-base/tests/paste-endpoint.test.mjs`、`skills/xws-export-market-analysis/tests/postgres-state.test.mjs`）。**51 是实跑数，53 是发现数，两个都对。**
- B-5 **不在 B-3 的发现面内**（因为它有自己的调用方式，登记在 `RUNTIME_OWN_INVOCATION_DIRS` 并附了理由）。**漏跑一次就是 355 条用例无声地不进回归。**

### 1.3 复现命令

```bash
node scripts/run-test-suite.mjs runtime --concurrency=1        # → 72 文件 / 537
node scripts/run-test-suite.mjs skills  --concurrency=1        # → 51 文件 / 609（约 20 分钟）
node --test runtime/sop-runtime/*.test.mjs                     # → 26 文件 / 355
node scripts/run-offline-self-tests.mjs                        # → rc=0，3 个 self-test 全 ok
node scripts/run-test-suite.mjs skills --skill=sycm-alimama-daily-report   # → 70/70（日报链单跑）
```

`--concurrency=1` 不是可选项：`xws-export-market-analysis` 的用例会拉起真实 CLI 打假代理并含 stall/deadline 计时断言，机器有负载时会**假失败**。想看各套件解析出的文件清单而不跑：加 `--dry-run`。

`--skill=` **必须与套件名同给**（`skills --skill=…`）；只给 `--skill=` 会打到 usage 退出 2。
