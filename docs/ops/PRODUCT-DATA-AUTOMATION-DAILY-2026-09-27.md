## 遇到的问题与解决

1. **推广报表下载被全屏活动浮层拦截。**
   - 原因：页面上存在覆盖层，DOM 点击成功但真实鼠标命中不到下载入口。
   - 解决：安全关闭覆盖层、重新发现页面 target、重新激活隐藏的任务操作行，并以 ZIP 文件实际落盘作为成功判据；失败最多刷新任务管理页重试三次。

2. **下载任务偶发最新任务不可下载。**
   - 原因：阿里妈妈下载任务页状态没有及时刷新，最新任务操作区可能未显形。
   - 解决：任务就绪后检查复选框和操作区可见性；不满足时刷新并重新发现 target，再执行真实鼠标点击。

3. **流程结束后浏览器没有释放。**
   - 原因：阶段脚本完成后没有统一 release 调用，`stop-all` 的退出码也不能单独作为释放证据。
   - 解决：总控使用 `finally` 无论成功失败都调用释放脚本，并对每家浏览器/代理端口做两次回读。

4. **商品三链没有接入原有日报定时入口。**
   - 原因：日报计划只调度日报链，阶段脚本不能直接作为无人值守任务。
   - 解决：新增独立总控入口和 WorkBuddy 交接规范，与日报任务保持独立，避免重复写入。

5. **受影响测试触发了不适合本次改动的长测试。**
   - 原因：项目的 affected 测试会带起全量技能测试，其中有真实浏览器等待和未安装 `pg` 的既有用例。
   - 处理：商品总控、浏览器端口、商品底单/询单/推广核心测试共 19 项定向测试全部通过；全量 affected 测试的 `pg` 缺失属于既有环境问题，未将其误报为商品流程失败。
