# 生意参谋自动化项目知识

## 项目定位

面向电商运营与市场分析工作的受控浏览器自动化项目。系统复用用户已登录的 Edge 会话，将生意参谋搜索排行、小旺神竞品分析、灰豚小红书话题热度、文件校验和飞书多维表导入拆成五个可复用 Skill，并为每一步设置明确的数据合同、安全停止条件和验收证据。

项目不是绕过平台风控的爬虫，也不承诺无人值守长期运行。遇到登录、验证码、账号风险、权限或安全提示时必须停止并交给用户处理。

## 已实现能力

### 生意参谋搜索排行导出

- 从生意参谋首页进入搜索排行并校验目标类目。
- 逐页读取页面展示的真实排名，不用页码和 DOM 位置推算排名。
- 固定导出 `排名、搜索词、搜索人气、点击率、支付转化率` 五个字段。
- 保留区间值与 `-`，不推断被平台隐藏的精确数据。
- 输出 CSV/XLSX 前校验排名连续唯一、搜索词非空、字段完整和文件可读。
- 已保留三轮各 267 行的离线稳定性工件。

### 小旺神市场分析导出

- 从淘宝首页完成关键词搜索、插件打开、参数配置、慢速采集监督和文件导出。
- 使用显式状态事件记录开始、配置、采集、进度、完成、失败和人工接管。
- 使用有界轮询和停滞判定，避免重复点击、刷新风暴或无限重试。
- 固定校验 16 列竞品数据、排名连续唯一、商品链接完整唯一、CSV/XLSX 非图片字段一致、XLSX ZIP 完整和嵌入图片可解码。
- 2026-08-05 两次真实完整运行分别覆盖 1-40 页、1343 行和 1333 行；两次结果差异被记录为实时淘宝结果变化，没有篡改数据去追求一致。

### 飞书多维表导入

- 只操作用户授权的模板副本，不修改原模板。
- 先保留表、字段、公式、视图、筛选、分组、排序和仪表盘结构，再向既有数据表写入五个源字段。
- 使用真实剪贴板与键盘粘贴路径，不依赖页面内伪造 ClipboardEvent。
- 导入前后校验字段顺序、源行数、首末排名、连续唯一排名和云端保存状态。
- 当前运行证据包含 267 条记录导入后的飞书副本界面；结构化验收回执仍需补齐，因此不把 AI 字段全部完成或长期稳定性写成已验证事实。

### 小旺神竞品图片 API 导入

- 从小旺神 XLSX 逐行提取内嵌商品图，不把图片链接当作附件。
- 复用既有飞书应用凭据，通过素材上传接口取得 `file_token`，再以 `[{ file_token }]` 写入附件字段。
- 写入前强制目标表为空、16 个源字段齐全、`商品图片` 为附件字段 `type=17`，避免覆盖既有数据。
- `价格` 写为数字；旧导出的 `月收货人数` 按数字字段处理并去除尾随 `+`；当前导出的 `付款人数` 使用文本字段，`14人看过`、`200+人看过` 等展示值原样保留，不推算；其他文本和 `-` 同样原样保留。
- 2026-08-06 在授权空副本完成 3 行真实验收：API 回读 3 条记录、3 个附件，浏览器中三张商品图均显示为真实缩略图。

### 灰豚小红书话题热度回填

- 从飞书公式产生的完整 `A候选` 队列读取关键词，从灰豚官网切换到红薯版“话题搜索”逐词查询。
- 只接受去掉首尾 `#` 后与搜索词完全一致的话题；相近话题不合并、不累加，查无同名话题明确记为 0。
- 第一版只使用运营确认的 `1000w` 分界：达到 1000 万为高，否则为低，不虚构中档阈值。
- 默认只生成本地 dry-run；复用结果必须匹配灰豚来源、24 小时时效、目标表和完整 `(record_id, 搜索词)` 队列指纹。
- 每次查询必须观察到点击后的 loading 或结果签名转换；点击前已有的旧结果或 spinner 不能作为本轮查询证据。
- 显式确认后只允许写入 `内容热度（后续）` 与 `灰豚话题浏览量`，写前备份，写后校验 `优先级` 公式收敛、字段、记录数和包括 `是否重点词` 在内的所有无关数据。
- 2026-08-14 在授权表完成两条真实验收：`家用浴缸` 精确命中 `#家用浴缸#`、展示值 `109.4w`、回填 `1094000`；`新型泡澡浴缸` 无同名话题、回填 `0`。两条均按公式收敛为 `B-持续观察`，无无关字段或记录变化。

## 工程设计

```text
已登录 Edge 会话
  -> 共享 CDP Proxy
  -> 页面目标重新发现
  -> 受控采集状态机
  -> 临时 CSV/XLSX
  -> 数据与文件双重校验
  -> 原子发布
  -> 授权飞书副本导入
  -> 行数与结构验收
  -> 飞书 A候选队列
  -> 灰豚红薯版同名话题采集
  -> 两字段回填与公式验收
```

- 浏览器控制：共享 `web-access` Proxy，所有动作前重新发现 target，导航后不复用旧 target id。
- 安全边界：不读取密码、Cookie、Token、浏览器存储或认证头；不加入 stealth、指纹伪装或反检测逻辑。
- 数据可靠性：页面展示值是事实源；插件文件名与页面结果冲突时保留原文件并记录告警。
- 失败处理：登录/验证/风控进入 `HUMAN_REQUIRED`；无进度进入 `STALLED`；校验失败的文件不得进入飞书。
- 可测试性：浏览器流程、CLI、参数准备、输出发布、文件校验、字段检查和粘贴合同均有离线回归测试；2026-08-14 灰豚 Skill 18 项、旧回填器 6 项、生意参谋 17 项及两个飞书兼容测试通过，Skill 结构与自检同时通过。

## 可用于简历的事实

- 将生意参谋、小旺神、灰豚与飞书之间的人工数据流拆成五个可复用自动化 Skill，覆盖浏览器操作、状态监督、CSV/XLSX 校验、结构保留式导入和受保护的话题热度回填。
- 为慢速第三方插件设计有界轮询、停滞检测、失败证据和人工接管机制，避免刷新与重试风暴。
- 两次真实完成小旺神 1-40 页竞品采集，分别校验 1343 和 1333 行、16 个字段及同数量嵌入图片；CSV/XLSX 非图片字段零差异。
- 完成生意参谋 267 行搜索排行数据的连续性校验与飞书副本导入，并保留三轮离线稳定性工件。
