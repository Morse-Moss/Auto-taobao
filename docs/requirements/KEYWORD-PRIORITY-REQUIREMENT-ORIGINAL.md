## 3. 现役公式原文（对齐基准）

从 `runtime/keyword-decision-formulas.mjs` 逐条抄，未改写：

```text
isExcluded   = 关键词分类="品牌词"
searchReady  = OR(搜索热度="中", 搜索热度="高")
tradeReady   = OR(交易热度="中", 交易热度="高")
contentReady = OR(内容热度="中", 内容热度="高")
isA          = AND(灰豚话题浏览量>=10000000, searchReady, contentReady, 交易热度="高")
isACandidate = AND(searchReady, contentReady, 交易热度="高", 灰豚待填)
isB          = AND(searchReady, tradeReady)
缺数据        = OR(关键词分类空, AND(关键词分类="痛点词", 细分标签空), 搜索热度缺失, 交易热度缺失)

优先级 = IF(ISBLANK(搜索词), "",
          IF(品牌词, "C-常规跟踪",
          IF(缺数据, "待数据",
          IF(isA, "A-立即跟进",
          IF(isACandidate, "A候选",
          IF(isB, "B-持续观察", "C-常规跟踪"))))))
```

## 4. 逐条对齐

### 一致（4 项）

1. **A 标准前两条** ←→ `isA` 的两个条件。脑图「交易热度高」对应 `交易热度="高"`；脑图「搜索人气中或以上」对应 `searchReady`（术语差异见 §2，语义一致）。
2. **A 标准第三条** ←→ `contentReady` + 灰豚门槛。脑图把「内容热度中或以上」写成「**再去灰豚验证，话题浏览量达1000w**」的触发条件 —— 这正是 `isACandidate`：A 的三项已满足、灰豚还没查，先进队列。**顺序是「内容热度」在前、「灰豚」在后**，两边一致。阈值也一致：脑图 `1000w` = 公式 `10000000`。
3. **C 标准「品牌词」** ←→ `isExcluded`，`关键词分类="品牌词"` 直接落 `C-常规跟踪`。
4. **C 标准「剩余不达标的」** ←→ 公式兜底分支：A、A候选、B 都不成立时落 `C-常规跟踪`。脑图第一句「根据以上的数据分类，再评分出A/B/C级别」与公式吃 `关键词分类` + 三档热度的做法也一致。

### 差异（3 项）

**D1 —— B 标准比脑图宽，会改变分类结果（不是措辞差异）**

脑图 B 只写「交易热度**中**」；公式 `tradeReady` 接受 `交易热度∈{中,高}`。落进差集的是这两类：

- (a) 交易热度高、搜索热度∈{中,高}、内容热度∈{中,高}，但灰豚**已有值且小于 1000w**：公式 → `B-持续观察`；脑图字面 → A 第三条没过（浏览量未达 1000w），B 第一条也不满足（不是「中」）→ `C-常规跟踪`。
- (b) 交易热度高、搜索热度∈{中,高}、内容热度为空或低：公式 → `B-持续观察`；脑图字面 → `C-常规跟踪`。

方向明确：**公式比脑图宽（B 更多、C 更少）**。

**D2 —— 「待数据」态与品牌词的短路，脑图都没写**

公式在「缺数据」（`关键词分类` 空 / `关键词分类=痛点词` 且 `细分标签` 空 / `搜索热度` 或 `交易热度` 缺失）时输出 `待数据`，且这一步**排在 A/B/C 之前**。品牌词更靠前：**先短路成 `C-常规跟踪`**，所以品牌词即使数据缺失也不会落「待数据」。脑图完全没有这两个状态。

**D3 —— 「竞争还不大」在现役公式里没有被实现（需求缺口）**

脑图的立论是「越高级越要快操作，例如一些新晋的关键词，趋势好、有需求、**但是竞争还不大**的时候，我们要迅速抓到这一波趋势」。但周表里**没有任何竞争度/竞争指数类字段**：`搜索人气`、`支付转化率`、`搜索热度`、`交易热度` 都不是竞争度，`支付转化率` 只是 `交易热度` 的分档来源。⇒ 优先级目前只由「三档热度 + 灰豚门槛 + 品牌词」决定，「竞争不大」这一条**没有被实现**。这是缺口，不是措辞问题。
