## 五、`got 0` 的完整因果链

```js
// skills/sycm-alimama-daily-report/scripts/inquiry-core.mjs:51-57
export function selectDailyStoreRecord(records, reportDateEpoch, shop) {
  const matches = records.filter(record => Number(record.fields?.['日期']) === reportDateEpoch
    && cell(record.fields?.['店铺']) === shop);   // ← shop 是「盖文淘宝」，字段值是 "optFFaXJeh"
  if (matches.length !== 1) {
    throw new Error(`expected one Feishu row for ${shop} / ${reportDateEpoch}, got ${matches.length}`);
  }
  return matches[0];
}
```

1. 09-28 这一天，表里**没有任何我方形态的行**（我方的行序列是 `…09-27 → 09-29`，独缺 09-28）。
2. 唯一存在的 09-28 行是另一套流程写的，`店铺` 存的是**选项 id**。
3. 两个条件同时不满足 ⇒ `matches.length === 0` ⇒ 抛 `got 0`。

**⇒ 报错信息是准确的**：「我方在 09-28 没有可回填的行」。
本轮回填失败**不是**因为读错了表，而是因为**这一天压根没有我方的行可写**。
