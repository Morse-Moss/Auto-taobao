## 色彩池（4 hex + 中性）

| 角色 | hex | 用途 |
| :-- | :-- | :-- |
| 主色 | `#1B3557` 深海军蓝 | 标题、表头、章节号、图表第一系列、页脚项目名 |
| 强调色 | `#AE4128` 砖红 | 只给"问题侧"：低效、错配、缺口、警示 |
| 点缀色 | `#A97B28` 金 | 章节号描边、行动项标记、金句下划线（面积 ≤ 3%） |
| 辅色 | `#F4F6F8` 浅灰蓝 | 卡片/表格底、图表背景、信息分区 |
| 中性 | `#15181D` 文本 / `#5F6975` 次级 / `#FFFFFF` 背景 / `#DDE2E8` 分隔线 | 文本与结构 |

面积分配：主色 ≤ 60%，辅色 ≤ 30%，强调色 ≤ 10%（Hero 页可到 15–20%），中性色剩余。Supporting 页强调色 ≤ 5%。Hero 页（01/05/09/11/14）与 Supporting 页比例显著不同，禁止全篇雷同。
渐变方案：`linear-gradient(135deg, #1B3557 0%, #42648F 100%)` 只用于封面左侧文字衬底与章节扉页底；半透明策略：图片上叠 `rgba(27,53,87,0.18)` 统一色调，卡片用 `boxShadow: '0 4px 18px rgba(20,30,45,0.08)'`。
禁忌：同页出现第二套主色板；高饱和撞色铺满 ≥ 1/3 页面；3D 图表。

## 信息密度与留白

常规内容页留白 ≤ 35%（本篇实际 20–28%），Hero 页 22–42%，章节扉页 40%。每页至少 1 个视觉锚点（≥ 96px 数字、≥ 40% B 区面积的图表或产品图）。卡片填充率 ≥ 85%，尾部元素用 marginTop:'auto' 钉底。焦点锚点周围留 ≥ 40px 呼吸空间。
