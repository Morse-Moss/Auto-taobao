## 4. 候选动作：一个都没执行，理由

| 候选 | 为什么没试 |
| --- | --- |
| `REAPPLY_DATES` | 它作用于 `stageHint=feishu` 的飞书底单页，用来「把日期筛选重新落位」。本次失败的页面根本不是决策点：`push` 只读本地 xlsx，stderr 是 Python 侧 `extract-sources.py` 抛的。改飞书页的日期筛选不会让本地文件多出一行。 |
| `RELOAD_PAGE` | 同上。重载飞书页既不产生 10-18 的数据行，也不改变导出文件。 |

判据：**动作必须能影响失败点**。这里的失败点是「源文件缺目标日行」，而两个候选的作用域是页面。
硬跑一次 `applied:true` 只会制造「动作成功」的假象（10-13 那次 `applied:true` 而动的是标识页，正是这一类）。
按作业指导书第 3 步，直接进入根因判断。

另外：`--proxy` 已按阶段算好为 19023（共用商家浏览器），这一台确实活着；但阶段本身不需要它。
