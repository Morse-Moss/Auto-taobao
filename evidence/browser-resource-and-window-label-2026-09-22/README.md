# 七个浏览器实例：资源账 + 窗口标志现状（2026-09-22 23:2x）

这份文件回答两个现场问题（全只读取证，未起停任何进程）：

1. **采集完不会关浏览器吗？这七个浏览器一直占系统资源。**
2. **每个浏览器有没有固定展示店名，以便登录失败转人工时业务人员能快速定位？**

一句话结论：

- 问题 1：**没有任何程序会自动关它们**（不是「忘了关」，是仓里根本没有这个调用），而且这是刻意的 ——
  这条链唯一必须人的环节是登录，而脚本**不能用浏览器里存着的密码自动登录**。关掉 = 把「可控的常驻内存」换成「不可控的登录中断」。
- 问题 2：**目前是半成品。** 七个窗口里只有 2 个在任务栏上显示店名；另外 3 家店虽然挂了标志页但它被挤到激活页签后面；
  竞品与商家两个实例**根本没有标志页**（标志页脚本只覆盖五家店）。

---

## 一、事实：谁负责关浏览器 → 没有人

| 判据 | 结果 |
| --- | --- |
| 唯一的停止器 | `scripts/stop-all.mjs`，**默认只打印**，要 `--yes` 才真停；每个实例「证据不到就拒停」；停后回读核对 |
| 谁调用它 | 全仓检索 `stop-all`，命中全是它自己的文档与测试（`runtime/stop-all-release-readback.test.mjs`、`runtime/launch-plan.mjs` 等）⇒ **没有任何自动化调用它** |
| 采集链跑完做什么 | 最后一步是回读核对，脚本随即结束，**不碰浏览器** |
| 谁挂窗口标志页 | `scripts/` 下检索 `shop-window-label` / `--front` ⇒ **零命中**。启动（`start-all.mjs`）与收尾都不挂标志页、也不置前 |

⇒ 「谁负责关」的答案是：**没有谁**。要关只能人显式下 `stop-all.mjs --yes`。

## 二、为什么刻意不关（第一性原理，不是懒）

出处：`../../docs/ops/FULL-AUTOMATION-STATE-CONTRACT-2026-09-21.md`（「关掉浏览器不是解法，而是把可控问题换成不可控问题」）。

关键事实链：

1. 这条链唯一必须人的事是**登录**。
2. 脚本**不能**用浏览器保存的密码自动登录：Edge 的自动填充只是**预览绘制**，值不进 DOM，页面自己的 JS 读不到
   （技能 `chromium-autofill-preview-vs-trusted-gesture`）。
3. 实测坐实第 2 条：五家店 profile 的 `Login Data` 里淘宝密码**都在**（密码长度 40），但登不上去。
   —— 用户此前那句「我看着都保存了，为什么不会自动登录」的根因就在这。
4. 所以浏览器一关，万一 cookie 失效，**没有任何自动手段恢复**，只能人工重登。

**说清楚代价**：关掉浏览器**不会丢**已保存的密码（`Login Data` 与 cookie 都在 profile 目录里，是持久文件）。
真正的代价是「下一轮跑之前必须有人在、且登录态得当」—— 这是把无人值守换成有人值守。

## 四、窗口标志现状（问题 2 的答案）

窗口标题 = **当前激活页签**的 `document.title`，任务栏与 Alt-Tab 显示的正是它。实测（把窗口按 PID 挂回实例）：

| 网林天猫 19032 | **网林天猫 · 日报采集窗口** 和另外 2 个页面 | ✓ |
| 盖文淘宝 19033 | 生意参谋 - 零售电商大数据产品平台 和另外 2 个页面 | ✗ |
| 科塔淘宝 19034 | **科塔淘宝 · 日报采集窗口** 和另外 3 个页面 | ✓ |
| 盖文天猫 19035 | 生意参谋 - 零售电商大数据产品平台 和另外 2 个页面 | ✗ |
| 竞品链 9222 | 我的淘宝 和另外 1 个页面 | ✗（且**没有标志页**） |
| 商家浏览器 19022 | 各店铺日报 - 飞书云文档 和另外 1 个页面 | ✗（且**没有标志页**） |

**为什么会这样**：五家店的标志页**都挂上了**（`03-label-readonly.json` 里 `labelTabs=1`、`needsLabelTab=false`），
而且内容完整（店名 + 实际登录会员名 + 判定 + 登录提示）。但**任务栏只显示激活页签的标题** ——
采集流程一切到生意参谋工作页，标志页就退到后面去了。旗舰 `--front` 只在 `--commit` 那一刻置前，之后没人再管。

**竞品 9222 与商家 19022 完全没有标志页**：`runtime/shop-window-label.mjs` 的覆盖范围只写了 `SHOP_BROWSERS`（五家店），
`PROJECT_PORTS` 里的竞品与商家两个实例不在其中。

## 五、钉住状态（`GET /health` 的 `pinnedTabs`，代理自己报的数）

| 代理 | managedTabs | pinnedTabs |
| --- | --- | --- |
| 竞品链 3457 | 0 | 0 |
| 商家浏览器 19023 | 1 | 1 |
| 里可林 19041 / 网林 19042 / 盖文淘宝 19043 / 盖文天猫 19045 | 2 | 2 |
| 科塔 19044 | 4 | 4 |

读出两件事：

- 五家店的页签**全部处于钉住状态**（`managedTabs == pinnedTabs`）⇒ 标志页不会被 15 分钟闲置回收，也不会随代理退出被关。
  代价是它们**永久驻留**在内存里（科塔那 4 个钉住的页签对应 1595 MB）。
- 竞品代理 `0 / 0` ⇒ 竞品实例的页签**不是代理建的**，不在任何回收管辖内，也没有标志页。

## 六、要做的两件事（对应问题 2，等拍板）

1. **每轮采集收尾把标志页重新置前**。能力已经有了（`shop-window-label.mjs --commit --front`），缺的只是**没人调用它**：
   接进收尾（或接进 `start-all` 之后的就绪检查），跑完一轮，五个窗口任务栏就全是店名。
2. **给竞品 9222 与商家 19022 也挂标志页**。需要把覆盖范围从「五家店」泛化到「全部声明实例」
   （`PROJECT_PORTS` 的两个也要有 `windowTitleFor` / `memberNameFor` / `show-window-label.html` 的对应条目，
   并同步 `runtime/shop-window-label.test.mjs` 的用例与 `runtime/arch-boundary.test.mjs` 的登记）。

转人工时业务人员手里的线索（第 1、2 项做完后变成四条）：
任务栏标题（店名）→ 标志页上的大字店名 → **标志页上「实际登录的会员名」（四态，登错店会标红）** → 登录提示。
第三条最有价值：它直接回答「这台机器现在登的到底是不是这家店」。

## 七、降本四条（按力度排序，全部需要授权）

| # | 层次 | 做法 | 省多少 | 代价 |
| --- | --- | --- | --- | --- |
| 1 | 用法层 | 跑完关掉、跑前再起（`stop-all.mjs --yes` / `start-all.mjs`） | 约 8.2 GB（峰值） | **中断性操作**；跑前必须有人在，登录态丢了要人工登；采集链的判据要跟着改 |
| 2 | 交付层 | 跑前加一道内存预检，可用内存低于阈值就 fail-closed 报警 | 0（防事故，不省内存） | 改动小、无副作用 |
| 3 | 启动参数层 | `--disable-gpu` 等省内存参数（GPU 那 2450 MB 在这儿） | 待实测 | **必须先 A/B 实测**（同一 profile 跑一轮采集看会不会坏），不许先写进生产 |
| 4 | 架构层 | 一个浏览器多 context，省掉重复的 GPU/browser 进程 | 数百 MB | **不建议**：context 隔离正是防串号的机制，不许为省内存冒险 |

顺带可清、不需设计的一笔：孤儿 PID 8812（**597 MB**，父进程已死，不属于任何实例）。
停它需要授权 —— 停进程属中断性操作。

## 复现

```bash
# 资源账 + 窗口标题（只读）
node evidence/browser-resource-and-window-label-2026-09-22/repro-browser-account.mjs
# 代理钉住状态（只读）
node evidence/browser-resource-and-window-label-2026-09-22/repro-agent-pin-health.mjs
# 窗口标志只读报告 / 浏览器对账（现成的生产 CLI）
node runtime/shop-window-label.mjs
node runtime/browser-inventory.mjs
```

原始输出：`01-live-account.txt`、`02-agent-pin-health.txt`、`03-label-readonly.json`、`04-inventory.txt`。

两个探针都**自定位**（`REPO_ROOT = import.meta.dirname/../..`）—— 从 `tmp/` 复制进 `evidence/<批次>/` 时，
`'../runtime/…'` 这种相对 import 会静默指向别处，所以这里显式改成 `../../runtime/…`（见技能 `evidence-copy-must-be-runnable`）。

量法口径（见技能 `browser-instance-resource-budget`）：实例数只从**权威登记表**数；
每个实例的内存用**浏览器自报的进程表**（CDP `SystemInfo.getProcessInfo`）拿 PID 再回系统进程表求和，不按命令行猜归属；
node 归属**按端口**（`netstat` 找 LISTENING）。
