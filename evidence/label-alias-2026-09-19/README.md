# 标签页上明说「同一个店的两个名字」（2026-09-19）

## 触发

用户贴出一张标签页截图并问：

> 已登录随心，还有[截图]，这个浏览器不是给随心定制的吗

截图里那一页的大标题是「盖文淘宝」（登记表与飞书「店铺」列里的**运营叫法**），
下面写着「会员名 随心品质定制:阿彦」（**阿里妈妈会员名**）。两套名字字面上毫无关系，
所以站在机器前的人会以为窗口认错了店。这是「同店四名」这个坑在**界面侧**的第三次发作
（前两次：窗口标题用了会员名、「没有科塔啊，五个店铺哪里有科塔」）。

## 判断

**没有认错店。** 19033 那台就是盖文淘宝。四家店的两套名字对照：

| 运营叫法（飞书/登记表） | 生意参谋页头 | 阿里妈妈会员名 | 会员 ID |
| --- | --- | --- | --- |
| 里可林淘宝 | 里可林家居 | 里可林家居:阿彦 | 2350600069 |
| 网林天猫 | 网林家居旗舰店 | 网林家居旗舰店:阿彦 | 7314426323 |
| 盖文淘宝 | 盖文全卫定制 | 随心品质定制:阿彦 | 887360146 |
| 科塔淘宝 | 科塔全卫定制 | j873522735:阿彦 | 412070158 |

（登记表唯一来源：`skills/sycm-alimama-daily-report/scripts/shop-identities.mjs`）

盖文那一家之所以看不出，是因为它的会员名里既没有「盖文」也没有「全卫定制」。

## 修法

只把两行并排放（大标题 + 会员名）仍然要人自己推「这两个名字是不是同一家」，
所以直接把那句关系写出来。页面新增一行：

> 同一个店的两个名字：飞书里叫「盖文淘宝」，这个窗口登的会员名是「随心品质定制:阿彦」。

与状态行/会员名同一口径：**两个名字都量到才显示**，缺一个整行不显示（不写半句，
半句话比不显示更误导）。这一行只放名字，不放任何凭据面。

## 判据

`runtime/shop-window-label.test.mjs` 第 39 条。断言**先剥注释再匹配**——突变 M2 一开始
是漏的：把赋值整行注释掉，判据照样全绿，因为注释掉的 `// alias.innerHTML = …`
仍然匹配得上。剥注释后复跑 5/5 全抓住。
